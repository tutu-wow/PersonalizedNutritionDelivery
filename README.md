## 项目简介

起因挺简单：点外卖的人只想吃口对胃的，可平台不会管你今天营养够不够。加班熬夜的人随手就点重油重盐，长期吃心里没数。所以这套系统把「健康档案」和「外卖」揉到一块——先知道你的身体情况、今天已经摄入多少，再告诉你这顿该点什么、为什么点它；后厨那头也不闷头出餐，环境温湿度、空气质量用传感器盯着，商家和平台都能看到。

系统采用 B/S 架构，前后端分离：后端 Java + SpringBoot + MyBatis-Plus，前端 Vue3 + Element-Plus，数据库 MySQL。

## 核心实现说明

### 1. 健康数据驱动的个性化点餐

把四类数据拼起来看：健康档案（身高体重、健康目标）、每日营养摄入记录、健康目标、历史订单。点餐时系统结合这些数据筛出更匹配的菜品，并且给出「为什么推荐这道」的说明，而不是简单按销量排。

### 2. AI 营养建议（含降级策略）

营养建议模块接入 DeepSeek，用大模型生成更贴近用户情况的建议。考虑接口可能没配置或调用异常，系统做了兜底：降级为规则化建议（按营养学规则生成），保证功能在演示和真实使用中都可用。

### 3. 物联网餐厨监测（MQTT 链路）

后厨部署环境监测设备，通过 MQTT 协议上报数据，系统实时采集：

- 温度、湿度
- 空气质量
- 光照强度
- 噪声
- 设备在线状态

采集结果同步到商家端和管理员端，做可视化展示与趋势分析，把餐饮环境管理搬到线上。

### 4. Echarts 数据可视化

用户端看营养摄入趋势，商家端看订单经营数据，管理端看平台营养摄入总览；设备与环境监测数据也以图表呈现，支持运营和管理决策。
